# Generated reference data

Nothing in this directory except this README and `ALIGNMENT.md` is committed to
the repository. The PNGs, PPU/RAM snapshots, sprite crops and CSV evidence are
all derived from the original ROM and are recreated locally with the scripts in
`tools/`.

The build does not need this directory. It only contains optional captures for
the `reference_pixels` test and for the manual analysis described in
`ALIGNMENT.md`. See the repository README for the export and capture commands.
